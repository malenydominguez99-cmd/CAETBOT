\# 🤖 CAETBOT | Asistente Virtual del Centro de Atención Empresarial



Prototipo web de orientación ciudadana desarrollado para facilitar la consulta de información general sobre trámites empresariales del \*\*H. Ayuntamiento Constitucional\*\*.



\## 🎯 Objetivo



Desarrollar una interfaz web con un chatbot interactivo que permita a la ciudadanía consultar información básica relacionada con los trámites y servicios del Centro de Atención Empresarial (CAE).



\## ✨ Funcionalidades



\- Página web con diseño institucional.

\- Interfaz de chatbot interactivo.

\- Respuestas automáticas mediante identificación de palabras clave.

\- Orientación general sobre apertura de establecimientos.

\- Información básica sobre requisitos y costos.

\- Diseño adaptable a diferentes tamaños de pantalla.



\## 🛠️ Tecnologías utilizadas



\- HTML5

\- CSS3

\- JavaScript

\- Google Fonts (Poppins)

\- Font Awesome

\## 📌 Alcance del prototipo



CAETBOT utiliza respuestas predefinidas mediante palabras clave. La consulta del estado de trámites mediante folio se contempla como una posible funcionalidad futura, pero todavía no está implementada.



\## 🏛️ Contexto de desarrollo



Proyecto desarrollado individualmente durante las prácticas profesionales en el \*\*Centro de Atención Empresarial (CAE)\*\* del H. Ayuntamiento Constitucional.
